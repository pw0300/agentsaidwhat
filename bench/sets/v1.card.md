# Constructed call set v1

Source: v1.json and v1.distribution.json, written by bench/make-set.mjs.

300 calls, seed 20261013; 90 clean calls (30%). Handwritten templates cover real estate sales, bank support, food delivery and telecom support, with English and two Hinglish script forms. Callers explicitly switch language. Fault counts include both labels in paired calls. Seeded selection never targets the same turn twice. Timings are constructed telemetry, not recorded audio.

The engine layers come from api/_voicebench.ts, with prompt from src/types.ts. Each label also stores the existing UI mapping. ASR maps to platform; LLM maps to prompt; TTS maps to voice-tts; VAD maps to vad; telephony maps to platform.

This measures detector and judge behavior on known injected faults, not real-world fault prevalence, acoustic quality, real ASR behavior on audio, or human-rated voice quality. Synthetic transcripts are easier than real calls. The template family is small and repeated; intervals describe this constructed set, not unseen production callers. The set is public and is not a blind holdout. Caller reference versus recognition text is a constructed substitution, not an ASR engine evaluation.
