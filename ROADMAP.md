# Roadmap

## Now

Manual call logging, version-pinned evidence, triage and fix verification work
locally with SQLite and recordings. Text simulations and model judging need
provider keys. Release gates evaluate recorded scores; missing evidence remains
inconclusive. Packaging, Docker and a read-only sample demo are prepared.
Publication still needs an available package name and real repository metadata.

## Next

Document and connect external adapters and caller drivers. Make scenario pack
import explicit in the UI. Add reviewed language and domain packs. Exercise the
release workflows on the real repository and validate the container in CI.
Improve disabled-action accessibility and judge setup feedback.

## Later

Collect permitted live audio and separated-channel timing evidence. Calibrate
judges against human ratings across languages and domains. Measure production
reliability and telephone latency. Hosted audio storage needs a privacy and
retention design before implementation. These are research and engineering
tasks, not measured capabilities or dated commitments.
