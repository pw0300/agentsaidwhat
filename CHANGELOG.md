# Changelog

All notable changes are documented here, using Keep a Changelog conventions.
Version numbers follow Semantic Versioning. Sample data and fixture results are
not live agent benchmarks.

## [Unreleased]

### Changed

- Renamed to Our Agent Said What?!

## [0.2.0] - 2026-10-13

### Added

- Versioned YAML scenario packs with optional caller turns.
- Gate output schema, Docker packaging and a tag-driven release pipeline.

### Changed

- Package contents include the built local UI and server without datasets.

## [0.1.0] - 2026-10-13

### Added

- Local React workbench with SQLite revisions, audio storage and manual call scoring.
- Version-pinned evidence, timestamped notes, triage, ownership and fix verification.
- Scenario library, text simulation and a multi-provider judge panel.
- Release gates with sample floors, parameter floors, blocker limits and regression checks.
- Hosted sessions, tenant storage, redaction, privacy export and signed gate receipts.
- Audio probes, ASR experiments and research notes with measurement limits.
- Keyboard call logging, command palette, call filters, issue navigation and undo.
- Apache-2.0 licence, dataset policy, contributor guidance and Node 22/24 CI.

This entry records the capabilities present in git history before the shipping
work. The date is the changelog's retrospective baseline, not a claim that an npm
release occurred. The package currently declares 0.2.0; tags must match it.
